# 📊 Data Professional Survey Breakdown (Power BI Dashboard)

An interactive Power BI dashboard that analyzes global survey data from data professionals. The report visualizes key industry metrics, including demographics, salary benchmarks, favorite programming languages, and career satisfaction trends.

---

## 🚀 Key Insights Provided
* **Industry Demographics:** Tracks the average age (**29.87**), total unique survey respondents (**630**), gender breakdown, and geographic distribution.
* **Salary Benchmarks:** Breakdown of average salaries by specific job roles and job titles.
* **Technology Trends:** Identifies the most popular programming languages among modern data professionals (Python, SQL, R, etc.).
* **Workplace Dynamics:** Gauges happiness metrics regarding work-life balance and current salary satisfaction levels.

---

## 🛠️ Tech Stack & Skills Demonstrated
* **Tool:** Power BI Desktop
* **Data Sources:** [e.g., Kaggle / Alex The Analyst Survey Dataset / CSV File]
* **Power Query:** Applied data transformations including column splitting, handling null values, and data type formatting.
* **DAX Formulas:** Developed custom measures for key metrics like unique counts, averages, and dynamic KPI tracking.
* **Data Modeling:** Established [e.g., Star Schema / Snowflake Schema] relationships between factual survey responses and lookup tables.
